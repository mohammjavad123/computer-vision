This project implements an automatic image colorization system using Conditional Generative Adversarial Networks (cGANs) based on a U-Net generator and a PatchGAN discriminator. The model is trained on a subset of the ImageNet dataset and predicts the a/b channels of the Lab color space given a grayscale (L-channel) image. We explore both training from scratch and using a pre-trained ResNet18 as the encoder for transfer learning. The model is trained with a combination of adversarial loss and L1 loss for more realistic and smooth outputs. Implemented in PyTorch, the system shows promising results on various datasets including ImageNet and COCO, and can generalize well to old black-and-white photos and real-world grayscale images.
